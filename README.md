# Moner Kotha
A cinematic Bengali music-platform MVP inspired by the atmosphere and interaction patterns of the provided Devi Paksha / Boithak references, with an original visual identity.

## Included
- Next.js + Tailwind + Framer Motion
- Mobile-first Pujo + Old Calcutta home experience
- Mood room, search, playlists, wishlist, persistent player UI
- Contributor modal for Sagnik Chakraborty with supplied profile photo and social links
- 52-song mock JSON database
- FastAPI API skeleton

## Run locally
1. Install Node.js 18.18+.
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

Backend: `pip install -r backend/requirements.txt && uvicorn backend.main:app --reload`

## Deployment
Deploy the Next.js app to Vercel by importing this repository from GitHub. The backend should later be deployed separately (e.g. Render/Railway/Fly.io) and connected through an environment variable.
